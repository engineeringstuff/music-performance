# Objective
Write code for a browser-based game in a Cloudflare Worker (or Pages) where a user will be scored based on their performance with a musical instrument.

# The game
1. A player is welcomed and shown the rules.
2. The player enters their details and game-configuration:
 * The player must select a musical instrument or vocals.
 * The player must select an audio-track.
3. The player is taken to the game-screen.
 * The game screen is ideally interactive and engaging to the player.
 * The player can start their game with a big green button.
   * Once the big green button is pressed there is a 3-2-1 countdown.
4. The player is playing the game
 * When the game starts the audio-track starts playing and the user must match the pitch and performance of the selected instrument for the duration of the audio-track.
 * As the game progresses the users score is collected/tracked.
5. The game ends
 * At the end of the audio-track there is a celebratory screen and the option to try again.
 * The player can exit the game at any time, but doing so forfeits their score.

# Constraints
 * We do not yet need a persistance layer - recording name, audio-track, score etc. is all in-browser (e.g. localStorage or IndexedDB).
 * I have no idea about a scoring system yet.
 * I do not know if pitch and duration is the right thing to audio-track.
 * I think the scoring should allow for some forgiveness of vocal-range (or instrumental range)

# Game Phases

## Phase 1
Phase 1 is purely a proof-of-concept, in-browser and simple. We will supply pre-approved CC-licensed MP3 or MIDI files for the backing-track, and we can compute the music data (e.g. timings, pitches and notes etc.) ahead of time.

## Phase 2
Phase 2 is more ambitious and will allow the user to upload their own MP3 music, and specify their desired instrument from the track. We will use SAM Audio (via https://fal.ai/models/fal-ai/sam-audio/span-separate/api) to extract that instrument and then distill it into a format containing timings, pitches and notes etc.

## Phase 3
Phase 3 is the productisation of this into a full-featured, interactive music-teaching tool for a variety of instruments and vocals.
