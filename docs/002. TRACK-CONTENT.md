# 002. Track content

This is the checklist for adding a Phase 1 backing track. A track is only listed in the
game once its audio, licence provenance and chart are all in place.

## Licence gate

Every track must be one of:

- **CC0 / public domain**, or
- **CC BY**, with the exact attribution text recorded.

Do not add a track whose licence is unclear, whose source URL is missing, or which
requires a share-alike or non-commercial condition without an explicit product decision.
The catalogue stores licence metadata and the UI displays it on the setup screen.

Record, for each track:

- `licence` — e.g. `CC BY 4.0`
- `attribution` — the exact credit line required by the source
- `sourceUrl` — the page the asset was obtained from

## Files

Use a stable lowercase track id, for example `twinkle-c-major`.

```
public/
  audio/<track-id>.mp3     Backing track
  charts/<track-id>.json   Pre-computed note chart
```

Files in `public/` are served from the site root, so the catalogue paths are:

```ts
audioUrl: "/audio/twinkle-c-major.mp3",
chartUrl: "/charts/twinkle-c-major.json",
```

MP3 is preferred for Phase 1 because it is small and supported everywhere. The audio
must be the complete performance; charts are timed from the first sample of the file.

## Chart format

Charts are generated ahead of time from MIDI and verified against the audio. They are not
computed in the browser.

```json
{
  "trackId": "twinkle-c-major",
  "sourceInstrument": "piano",
  "tempoBpm": 100,
  "notes": [
    { "startSec": 0.0, "durationSec": 0.5, "midi": 60, "lyric": "Twin" },
    { "startSec": 0.5, "durationSec": 0.5, "midi": 60, "lyric": "kle" },
    { "startSec": 1.0, "durationSec": 0.5, "midi": 67, "lyric": "twin" },
    { "startSec": 1.5, "durationSec": 0.5, "midi": 67, "lyric": "kle" }
  ]
}
```

Field rules:

- `startSec` and `durationSec` are seconds from the start of the audio file, not beats.
- `midi` is the reference pitch as written. Range fitting happens at play time.
- `lyric` is optional; use it for vocal tracks and omit it for instrumental ones.
- Notes must be sorted by `startSec` and must not overlap unless the source material
  genuinely does (the scoring design may reject overlaps).

The TypeScript shape is `TrackChart` in [`src/shared/domain.ts`](../src/shared/domain.ts).

## Adding the catalogue entry

After the files are in place, add a `TrackSummary` to `src/worker/catalog.ts`:

```ts
{
  id: "twinkle-c-major",
  title: "Twinkle, Twinkle, Little Star",
  artist: "Traditional",
  durationSec: 30,
  difficulty: "easy",
  licence: "CC0 1.0",
  attribution: "Performed and released by <artist> under CC0 1.0",
  sourceUrl: "https://example.com/source",
  audioUrl: "/audio/twinkle-c-major.mp3",
  chartUrl: "/charts/twinkle-c-major.json",
}
```

`durationSec` must match the audio file after decoding. The setup screen shows it before
the performance starts.

## Verification checklist

- [ ] Licence permits use and redistribution; attribution and source URL are recorded.
- [ ] Audio decodes in Chrome, Safari and Firefox.
- [ ] `durationSec` matches the decoded audio duration (within 100 ms).
- [ ] Chart note count and first/last note timings line up with the audible melody.
- [ ] Every note is inside the chosen source instrument's written range.
- [ ] Chart file is valid JSON and parses as `TrackChart`.
- [ ] Catalogue entry loads through `GET /api/tracks`.
- [ ] Setup screen displays the track, duration and licence.
- [ ] A human plays along once and confirms the target notes are the melody they hear.
