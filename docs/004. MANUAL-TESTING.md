# 004. Manual test checklist

Automated tests cover pure logic, API/content validation, component states, and
Chrome/Chromium browser flows. These checks still require a human, a real microphone or
MIDI instrument, and real devices before a public release.

Record the date, browser/version, OS/device, microphone or MIDI device, and headphones
used. File any mismatch with a screenshot/trace and, where possible, the local diagnostics
from **Privacy & data**.

## Browser matrix

- [ ] Chrome stable on macOS
- [ ] Safari stable on macOS
- [ ] Firefox stable on macOS
- [ ] iOS Safari on a physical iPhone (portrait and landscape)
- [ ] Android Chrome on a physical device (portrait and landscape)
- [ ] PWA install + launch from the home screen (Chrome/Android and Safari/iOS)
- [ ] Keyboard-only pass and reduced-motion pass

## Microphone and audio

- [ ] Permission prompt appears only after pressing Start.
- [ ] Denying permission shows the recoverable error; allowing it after retry works.
- [ ] Cancelling while the permission prompt is pending does not leave the mic indicator on.
- [ ] A quiet voice/instrument is detected; a noisy room is rejected by clarity.
- [ ] Low voice (C3 range) and high instrument notes are detected.
- [ ] Backing and guide stems start together after the countdown.
- [ ] Guide toggle and volume settings take effect on the next run.
- [ ] Count-in clicks align with 3-2-1 and the first audio beat.
- [ ] Pause freezes audio and timer; Resume continues in sync.
- [ ] Forfeit confirmation pauses; Keep playing resumes; forfeiting discards the score.
- [ ] Page-leave warning appears during an active run.
- [ ] Wired headphones: backing does not leak into scoring.
- [ ] Speakers with echo cancellation on and off: note whether pitch tracking is steadier and whether sustained notes sound thin.
- [ ] Stay silent through a backing phrase: the score must not rise as if the player sang the backing.
- [ ] Sing in the written octave, then an octave below and above: the ball stays in the lane and tracks the same pitch class.
- [ ] Bluetooth: document the observed latency and whether the timing offset helps.
- [ ] Timing offset positive corrects a consistently late-feeling run; negative corrects early.

## MIDI

- [ ] MIDI option only appears when Web MIDI is available.
- [ ] A connected keyboard is found; Start succeeds without a microphone prompt.
- [ ] Note-on/off and repeated notes score correctly (including repeated pitches).
- [ ] Disconnecting the keyboard mid-run produces a clear error, not a silent zero.
- [ ] No-device start shows the "No MIDI input was found" error.
- [ ] Multiple MIDI inputs work; the highest held note is used.

## Scoring and UI

- [ ] Target lane is readable on desktop and mobile; dense tracks (Bach) remain legible.
- [ ] Pitch ball, cents, streak and score respond without obvious lag.
- [ ] Hold a steady note: the ball is stable, with at most a small vibrato movement.
- [ ] Move across a note boundary while holding the previous note: the ball must not jump an octave when the target changes.
- [ ] Sing a deliberate wrong note outside the chart range: the ball stays visible at the lane edge with the amber off-range ring, rather than disappearing.
- [ ] A missed note and a held repeated note are both distinguishable in feedback.
- [ ] Key selector changes the backing key and the chart target together.
- [ ] Range-fit preview matches the shift applied at the run.
- [ ] Results note strip, phrase trend, best and share work.
- [ ] Refreshing Results reopens the same snapshot without double-saving.
- [ ] History shows clean bests; a guide-assisted run is saved but does not replace the best.
- [ ] Try again / Change setup / Back to start all navigate predictably.
- [ ] iOS safe areas and landscape do not clip controls.
- [ ] Screen reader announces countdown/target changes and can operate the forfeit dialog.
- [ ] Colour-blind check: rating symbols/legend and focus states are understandable.

## Privacy and data

- [ ] Privacy & data lists the correct result count.
- [ ] Clearing local data removes name, results, caches and the service-worker registration.
- [ ] A partial clear failure is reported and does not silently navigate away.
- [ ] No audio leaves the device; inspect the network panel during a run.
- [ ] Service-worker caches contain only app/content assets, not audio recordings or personal data.

## PWA and security

- [ ] Manifest installs with the maskable icon and correct theme colour.
- [ ] First online load → offline reload works with a cold HTTP cache.
- [ ] Offline Setup loads the cached catalogue; offline History and Mic check load their chunks.
- [ ] A missing `/audio/*` or `/charts/*` returns 404, not the app shell.
- [ ] CSP, Permissions-Policy, HSTS, Referrer-Policy and frame headers are present in production.
- [ ] A content update increments the service-worker cache version and does not break an old tab.
- [ ] `npm run content:validate` passes from a checkout without the soundfont.
- [ ] Re-render content with `npm run content:build` and verify metadata/durations.

## Release sign-off

- [ ] Legal review of the FluidR3Mono licensing caveat and notices.
- [ ] No known CC BY-NC/ND/SA assets or unclear provenance.
- [ ] All source/audio hashes and `content/content.lock.json` committed.
- [ ] CI green (lint, typecheck, coverage, content, build, dry run, dev E2E, PWA E2E).
- [ ] Cloudflare deploy tested on the target free account with a documented rollback.

## Pitch diagnostics capture

Use this when pitch tracking or the pitch ball behaves differently on a real device.

1. Open **Privacy & sound → Pitch diagnostics (debug)**.
2. Tick **Record the next performance**.
3. Play a short run with the problematic microphone, speaker/headphone setup and
   echo-cancellation setting.
4. Return to **Privacy & sound** and use **Download JSON** (or copy it).
5. Attach the JSON to the bug report. It contains numeric pitch/level frames, the microphone
   label, browser-reported audio settings and the lane range. It contains no audio, player
   name or device IDs, and it stays in this tab's session storage.
